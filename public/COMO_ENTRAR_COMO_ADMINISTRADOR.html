🔐 Cómo Entrar como Administrador

Guía paso a paso para crear y acceder con credenciales de administrador

1

Crear Usuario en Supabase Auth

Primero necesitas crear un usuario en el sistema de autenticación de Supabase:

  1. Ve a Supabase Dashboard → Authentication → Users
  2. Haz clic en "Add user" → "Create new user"
  3. Completa los campos:
    Email: admin@ieslopedevega.es
    Password: Admin2026!
    Auto Confirm User: ✓ (marca esta casilla)
  4. Haz clic en "Create user"
2

Crear Perfil de Administrador

Ahora necesitas crear el perfil del usuario en la tabla users:

  1. Ve a Supabase Dashboard → SQL Editor
  2. Copia y pega este SQL:
INSERT INTO users (id, email, name, role, active) SELECT id, email, 'Administrador del Centro', 'admin', true FROM auth.users WHERE email = 'admin@ieslopedevega.es' ON CONFLICT (id) DO UPDATE SET role = 'admin', active = true, name = 'Administrador del Centro';
  1. Haz clic en "Run" (o presiona Ctrl+Enter)
  2. Deberías ver: "Success. No rows returned"
3

Verificar que el Administrador fue Creado

Ejecuta esta consulta para verificar:

SELECT id, email, name, role, active FROM users WHERE role = 'admin';

Deberías ver tu usuario con role = 'admin' y active = true

4

Iniciar Sesión en la Aplicación

Ahora puedes iniciar sesión en la aplicación:

🔑 Credenciales de Administrador

Email: admin@ieslopedevega.es
Password: Admin2026!
  1. Ve a la página de login de tu aplicación
  2. Ingresa las credenciales de arriba
  3. Haz clic en "Acceder"
  4. Deberías ver el Dashboard con acceso completo de administrador
⚠️ Importante: Si ves el error 500 (Internal Server Error) en la consola del navegador, ejecuta primero el script fix-users-final.sql desde la página /setup de la aplicación.

Todos los scripts están disponibles en la página /setup de la aplicación:
