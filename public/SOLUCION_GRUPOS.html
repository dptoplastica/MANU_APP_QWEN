🔧 Solución: Error al Editar Grupos

Guía paso a paso para resolver el problema de permisos en Supabase

⚠️ Problema Identificado

Las políticas de seguridad (RLS) de Supabase están bloqueando las actualizaciones en la tabla groups. Esto impide que puedas guardar los cambios cuando editas un grupo.

1

Descargar el Script de Solución

Haz clic en el botón para descargar el script SQL que corregirá el problema:

📥 Descargar fix-groups-direct.sql
2

Abrir el SQL Editor de Supabase

Abre el SQL Editor de tu proyecto de Supabase:

🔗 Abrir SQL Editor
3

Copiar y Ejecutar el Script

Sigue estos pasos:

  • Abre el archivo fix-groups-direct.sql que descargaste
  • Copia TODO el contenido del archivo
  • Pégalo en el SQL Editor de Supabase
  • Haz clic en el botón "Run" (o presiona Ctrl+Enter)
-- El script debe ejecutarse completo sin errores
-- Verás mensajes de confirmación al final
4

Verificar tu Rol de Usuario

El script te mostrará tu usuario actual. Si tu rol NO es admin, ejecuta esta consulta:

UPDATE users
SET role = 'admin', active = true
WHERE id = auth.uid();
5

Recargar la Aplicación

Después de ejecutar el script:

  • Recarga la aplicación con Ctrl+F5 (o Cmd+Shift+R en Mac)
  • Ve al panel de administración
  • Intenta editar un grupo nuevamente

✅ Resultado Esperado

Después de seguir estos pasos:

  • Podrás editar grupos sin errores
  • Los cambios se guardarán en Supabase
  • Los cambios persistirán al recargar la página

🔍 Si el Problema Persiste

Si después de ejecutar el script sigues teniendo problemas:

  • Abre la consola del navegador (F12)
  • Intenta editar un grupo
  • Copia los mensajes de error que aparecen en la consola
  • Comparte esos mensajes para diagnóstico adicional
